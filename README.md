# Alexandra — персональный фитнес-тренер

Одностраничный сайт на чистых HTML, CSS и JavaScript (без сборщика и библиотек). Стек сохранён из исходного проекта.

## Запуск

```bash
cd aleksandra-portfolio
python3 -m http.server 8000
```

Откройте http://localhost:8000 (можно и просто открыть `index.html`; шрифты и фото подключаются относительными путями).

## Структура

- `index.html` — разметка (секции: Hero, Обо мне, Мой путь, Подход, Результаты, Отзывы, Образование, Процесс, Форматы и стоимость, Контакты)
- `styles.css` — дизайн-токены в `:root`, секции по порядку, адаптив в конце файла
- `script.js` — анимация появления, параллакс героя, меню, лайтбокс (без зависимостей)
- `fonts/` — локальные шрифты (WOFF, лицензия OFL)
- `photos/` — все изображения в WebP; `hero-cutout.webp` — фото с удалённым фоном для главного экрана

## Как менять

- Цвета и шрифты: переменные в начале `styles.css` (`--wine`, `--paper`, `--inst`, `--serif`, `--mono`).
- Главное фото: заменить `photos/hero-cutout.webp` (PNG/WebP с прозрачным фоном, голова в верхней части кадра) и поправить `width`/`height` у `#heroFigure` в `index.html`. Размер ~960×1440 px и вес до 150 КБ — больше не нужно.
- Подписи и размер галерей: объект `galleries` в `script.js`.
- Тарифы и тексты — прямо в `index.html`.

## Перед публикацией

0. Впишите свой домен: `canonical`, `og:url` и абсолютный URL в `og:image` (см. комментарий в `<head>`), иначе превью в мессенджерах не подтянется.

1. Подтвердите привязку килограммов к каждой клиентке (значения перенесены из исходного ТЗ).
2. Проверьте согласие на публикацию фото клиенток и скриншотов отзывов на сайте.
3. Проверьте персональные данные на дипломах и скриншотах.
4. Проверьте ссылки Telegram и Instagram.
5. Если есть исходник портрета с прозрачным фоном в высоком качестве, замените `photos/hero-cutout.webp`: текущий вырез сделан автоматически (GrabCut) и на волосах и краях заметно менее точен, чем ручная обработка.
